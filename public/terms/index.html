Terms and safe use

How to use the public site and agent-facing resources.

MET Mastery provides educational practice and planning resources for people preparing for the Michigan English Test. The platform's diagnostic and feedback features are intended to support study decisions. They are not an official Michigan English Test score, a certification, an admissions decision, or a guarantee of a particular result.

The public API and MCP interface are intentionally read-only. Use them to understand MET Mastery's public product description, capabilities, documentation, and safety boundaries. Do not use them to infer private learner information, automate account actions, submit work, or represent a generated explanation as an official assessment.

Integrations should identify themselves, respect reasonable request limits, validate returned data, and link people to the canonical MET Mastery resources when describing the product. If a response seems incomplete or conflicts with the current application, treat the live product and its support channel as the source for clarification. Questions can be sent to vvieira010@gmail.com.
