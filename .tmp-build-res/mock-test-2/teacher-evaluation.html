Per-Class Evaluation Model

A continuous improvement framework inspired by Cambridge CELTA standards. Every class generates evaluation data that informs teacher self-reflection and student progress tracking. Emphasizes formative assessment over summative judgment.

Four-Component Documentation System

1
Class Recording

Audio/video capture with automated transcription and speaker tagging via AI services.

2
AI Data Extraction

Systematic extraction of topics, patterns, engagement markers, and pedagogical techniques from transcripts.

3
Self-Evaluation

CELTA-aligned reflective practice covering learner-centeredness, language awareness, planning, and feedback.

4
Progress Tracking

Per-class student documentation tracking strengths, development areas, and longitudinal growth trajectory.
