MET Mastery

Developer portal

Public API, OpenAPI, MCP, and guidance for safe agent integrations.

This portal is the starting point for developers and AI agents that need reliable public information about MET Mastery. The available interfaces describe the product, its intended learners, and its agent-facing resources. They are designed for discovery and integration only; they do not provide access to teacher accounts, student records, submitted work, or other private data.

Quickstart

  1. Call GET /api/v1/info to retrieve the public product summary and canonical resource links.
  2. Read the OpenAPI 3.1 contract for typed REST operations and JSON problem responses.
  3. Connect to /mcp using Streamable HTTP and JSON-RPC to list the declared read-only tools.
  4. Read agent instructions for when MET Mastery is appropriate and its data boundaries.

Access and safety

The public API does not require an API key because it intentionally exposes only product-level information. It is not an account API and cannot begin a diagnostic, submit an exercise, retrieve feedback, or modify a user. If an integration needs a learner-specific action, it must use the authenticated product experience with explicit user consent and evidence.
