MET Mastery

Developer resources

Public, read-only interfaces for agents and integrations.

MET Mastery exposes a small public information surface for developers and AI agents. It is designed to make the product understandable and callable without opening student or teacher data. Start with the product information endpoint, then use the machine-readable contract that matches your integration.

Canonical resources

  • Public product information — JSON capabilities and canonical links.
  • OpenAPI 3.1 contract — read-only HTTP endpoints.
  • MCP endpoint — Streamable HTTP JSON-RPC endpoint for product and developer guidance.
  • llms.txt and agents.md — when-to-use guidance and boundaries.
  • MCP server manifest and server card — discovery metadata.
Authentication: The public endpoints do not require authentication. They deliberately do not expose private application operations. Treat links and response content as public documentation, not as permission to access an account.
